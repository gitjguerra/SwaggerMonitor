📊 Monitor de Swagger

🧩 ¿Qué es?

El Monitor es una aplicación que permite visualizar en tiempo real:

  • 📡 Estado de servidores
  • 📄 Documentación Swagger/OpenAPI
  • ⚡ Métricas (latencia, uptime, downtime)
  • 🚨 Alertas automáticas

⚙️ Configuración

application.yaml

monitor: swagger: external-dir: C:/DevEnvironment/src/java/monitor-workspace/swagger

📌 Aquí se almacenan los archivos Swagger generados por el SwaggerGenerator.

👀 Swagger Watcher

El servicio SwaggerWatcherService monitorea cambios en archivos Swagger:

  • ✅ Creación (CREATE)
  • ✅ Modificación (MODIFY)
  • ✅ Eliminación (DELETE)
🔥 Cambio detectado: ENTRY_MODIFY → simf.json

📌 Permite actualización en tiempo real sin reiniciar el sistema.

🌐 Endpoints Swagger

📦 Lista de Swagger

GET /api/swagger/files

📄 Obtener Swagger

GET /swagger/{name}.json

Ejemplo:

/swagger/simf.json
  • ✅ Busca primero en carpeta externa
  • ✅ Luego en classpath
  • ✅ Soporte case-insensitive

📊 Dashboard

GET /
  • 📈 Estado de servidores
  • ⏱️ Tiempo de respuesta
  • 📉 Históricos
  • 🚨 Alertas

🚨 Alertas

GET /api/alerts
TipoDescripción

📈 Eventos

GET /api/events

🔁 Flujo Completo

SwaggerGenerator → genera JSON ↓ Carpeta externa ↓ SwaggerWatcherService detecta cambios ↓ MonitorController sirve el Swagger ↓ Swagger UI lo renderiza

✅ Buenas Prácticas

  • ✔ Definir carpeta externa correctamente
  • ✔ Mantener nombres consistentes (simf.json)
  • ✔ Validar JSON generado
  • ✔ Evitar cache en desarrollo
